# SVG Generator Contribution Guidelines

## Introduction

Thank you for considering contributing to SVG Generator! This project renders banner and badge SVGs entirely in the browser. Your contributions keep it useful and growing.

## Code of Conduct

Before contributing, please review our [Code of Conduct](https://github.com/charudatta10/svg-generator/blob/main/CODE_OF_CONDUCT.md). We expect all participants to follow these principles.

## How to Contribute

1. **Fork the Repository**: Start by forking the SVG Generator repository to your GitHub account.

2. **Clone the Repository**: Clone your forked repository to your local machine using `git clone`.

3. **Create a Branch**: Create a new branch for your contribution using a descriptive name (e.g., `feature/awesome-badge`).

4. **Make Changes**: Write your code, templates, or documentation. Follow the existing coding style and conventions. To add a new SVG template, see [`docs/how-to-add.md`](docs/how-to-add.md).

5. **Test Your Changes**: Ensure your templates render correctly in the app and do not break existing functionality.

6. **Commit and Push**: Commit your changes with clear commit messages and push them to your forked repository.

7. **Create a Pull Request (PR)**: Open a PR from your branch to the `main` branch of SVG Generator. Provide a detailed description of your changes.

8. **Review and Iterate**: Collaborate with maintainers and other contributors. Address feedback and make necessary adjustments.

9. **Celebrate!**: Once your PR is merged, celebrate your contribution!

## Licensing

## Questions or Assistance?

If you have any questions or need assistance, feel free to reach out to the maintainers or create an issue.

Thank you for being part of the SVG Generator community!
