Create custom badges without installing anything.

## ✨ Features

- 🚀 Single HTML file
- 📦 Zero dependencies
- 🌐 Works completely offline
- 🎨 Multiple color presets
- 🌈 Custom left and right colors
- 🔲 Rounded or square badges
- 🖼️ Live SVG preview
- 📋 One-click SVG copy
- 📄 Download as SVG
- ⚡ Instant rendering
- 💻 Cross-platform
- 📱 Responsive interface

## 🚀 Quick Start

### Option 1

Clone the repository

```bash
git clone https://github.com/chaito10/badge.git
```

Open

```
index.html
```

in your browser.

### Option 2

Download the HTML file and double-click it.

No installation required.

## 🎨 Usage

1. Enter left text.
2. Enter right text.
3. Choose colors.
4. Select badge style.
5. Preview updates instantly.
6. Copy SVG or download it.

## Why?

Most badge generators require:

- Internet connection
- External APIs
- Frameworks
- Installation

This project keeps everything inside a single HTML file that works anywhere.
